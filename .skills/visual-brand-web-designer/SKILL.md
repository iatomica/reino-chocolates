# Visual Brand Web Designer Skill

## Purpose
Translates visual references and packaging identities into production-quality boutique web applications with high visual fidelity.

## Workflow
1. **Analyze visual primitives**: Extract color tokens, typography scale, surface textures, border styles, and photographic treatment.
2. **Establish design system**: Define semantic design tokens (`src/styles/tokens.css`).
3. **Build ornamental library**: Create custom SVG decorations (`src/components/ornaments/`).
4. **Implement layout architecture**: Construct responsive editorial compositions with high visual fidelity.
5. **Execute Visual QA Loop**: Validate against visual references and iterate until target fidelity is reached.
